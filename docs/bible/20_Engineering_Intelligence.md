# Purpose

The Engineering Intelligence layer converts reasoning into practical,
actionable audio engineering guidance.

------------------------------------------------------------------------

# Position

``` text
Measurements
      │
      ▼
Reasoning Engine
      │
      ▼
Engineering Intelligence
      │
      ▼
Report Generator
```

------------------------------------------------------------------------

# Responsibilities

-   Prioritize issues
-   Recommend processing chains
-   Suggest plugins and techniques
-   Estimate impact
-   Explain trade-offs

------------------------------------------------------------------------

# Inputs

-   Deterministic measurements
-   Reasoning output
-   Retrieved engineering knowledge

------------------------------------------------------------------------

# Outputs

-   Issue list
-   Recommended actions
-   Processing order
-   Engineering rationale
-   Improvement roadmap

------------------------------------------------------------------------

# Core Functions

## Problem Detection

Identify technical deficiencies.

## Prioritization

Rank issues by engineering impact.

## Recommendation Engine

Generate actionable solutions.

## Processing Planner

Create logical processing chains.

## Explanation Generator

Produce concise engineering justification.
